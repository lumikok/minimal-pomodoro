# 数据与版本控制

Git 仅用于代码、通用产品文档、锁文件与合成测试用例。学习次数、时长、设置、窗口位置、运行日志、真实数据备份和本机安装清单属于私人材料，不参与提交或发布。

正式数据默认保存在用户应用数据目录；项目内私人材料统一放入已忽略的 `local-records/`。开发数据放入已忽略的 `.data/`，便携数据目录 `portable-data/` 和 `userdata/` 同样忽略。状态文件、迁移备份和本机清单另有文件名忽略规则。

个人使用或维护应用不应产生 Git 提交。测试文档仅记录合成用例、通用构建结果与产品验收范围，不记录真实使用过程或电脑设置。提交前检查暂存文件；不要使用强制添加来提交被忽略的私人文件。
