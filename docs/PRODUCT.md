# 产品规则

## 目标

减少开始学习和安排休息的操作成本。默认 25 分钟专注，允许快速选 50 分钟或自定义；应用只计时，复盘交给拾光。

## 窗口草图

```text
┌──────────────────────────────────┐
│ 极简番茄钟             置顶 · 设置 │
│                                  │
│       专注 / 短休息 / 长休息       │
│                                  │
│              25:00               │
│          给这一段时间留白          │
│                                  │
│     25 分钟   50 分钟   自定义     │
│                                  │
│          开始专注     重置         │
│                                  │
│     今日 0 次 · 已完成专注 0 分钟  │
└──────────────────────────────────┘
```

上图保留为 v0.1 界面记录。v0.2 默认使用 220×100 透明浮窗：左侧阶段和大号倒计时，右侧开始／暂停和展开按钮。展开为 360×520 面板，设置区域可滚动；到点变为 320×224 的完成卡片。三种形态共用一个窗口和同一计时状态。

无标题栏，暖白底色默认 80% 不透明度，可调 40–100%，文字保持清晰。拖动时间区域或面板顶部移动，位置自动保存；默认置顶，可取消。展开时在显示器工作区内调整位置，收起回到记住的位置；显示器移除后返回可见区域。

## 时长与状态

- 专注默认 25 分钟，快捷预设 25/50 分钟；三个阶段都接受 1–180 的整数分钟。
- 短休息默认 5 分钟，长休息默认 15 分钟。
- 状态为待开始、运行中、已暂停、已完成。开始/暂停/继续的按钮随状态变化。
- 保存设置不影响已开始的阶段，下一段使用新设置。待开始时立即显示新时长。
- 暂停不累计时间；重置未完成且已开始的阶段需确认，重置不计统计。
- 切换阶段若会放弃已开始的未完成段也需确认，禁止绕过重置确认。
- 每个完整专注结束只计一次，之后推荐短休息，每四轮推荐长休息；下一段总是手动开始。
- 完成后的界面保留完成提示与推荐动作，可跳过休息直接开始下一次专注。

## 提醒与桌面行为

- 到点发一次静音系统通知，自动显示置顶完成卡片，即使之前隐藏到托盘也会出现；不抢键盘焦点。原创铃声播放约 10 秒后停止，可关闭声音或立即点击「静音」。
- 完成卡片保留到确认。「开始短休息／长休息／专注」手动开始推荐段；「稍后」只收起提醒，不开始下一段。重启仍显示未确认卡片，但不重新响铃。
- 系统通知被禁止或失败时，窗口与托盘仍显示完成状态；错误不影响统计。
- 置顶默认打开，可取消；面板 × 明确标注隐藏至托盘。托盘提供显示、暂停/继续、退出。
- 重复启动只显示已有窗口。
- 最小化、隐藏、锁屏继续计时；系统休眠冻结，唤醒继续。退出重开恢复未完成段为暂停，不补记离线时间。

## 数据

- 默认显示累计次数和已完成专注时长，支持「今日」切换。只累计完整专注段；放弃和休息不计。
- 跨午夜的专注归完成时本地日期；日期变化只清空今日数据，累计不清空，不影响当前计时。
- 完成次数的四轮循环与今日显示独立，重启不丢失，避免跨午夜打断循环。
- v0.2 保存当前日期汇总、累计汇总、可替换历史补录、循环次数、设置、当前计时快照、提醒确认状态与窗口偏好，不积累历史明细。
- 升级先保存原文件备份，再将旧版仍保留的那一天纳入累计，并标明现存记录起点。已覆盖的往日记录无法自动恢复；可补录缺失的次数和分钟，再次保存替换原补录值，不重复叠加，也不改变今日与四轮循环。
- 倒计时不足一小时显示 `MM:SS`，达到一小时显示 `H:MM:SS`；统计显示 `45 分钟`、`1 小时`、`1 小时 20 分钟`，不改变内部保存的时长。
- 开发数据在项目 `.data/dev`；正式版在用户应用数据目录。

## 验收

可完整执行专注→提醒→手动开始休息→再次专注；支持暂停、重置、调时、置顶、托盘和退出恢复。休眠/改系统时间不误计，完成事件不重复统计，损坏数据保留并提示。

v0.2 重点核对跨日和重启累计保留、补录不重复计算、59/60/61 分钟显示、托盘到点自动出现、约 10 秒铃声及静音、持续提醒和手动下一段。检查底色可读性、拖动和位置恢复、不同缩放及显示器移除后的可见范围；先独立数据验收，再升级安装版并检查迁移与系统通知。
