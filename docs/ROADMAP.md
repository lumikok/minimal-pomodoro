# 产品路线

## v0.1

- 中文离线番茄钟，专注、短休息和长休息。
- 暂停、继续、重置、手动进入下一阶段及四轮长休息规则。
- Rust 统一计时、数据存储、托盘、通知、声音、置顶和单实例。
- Windows 当前用户安装包，原创应用图标。

## v0.2

- 透明常驻浮窗，点击展开面板，保存位置与底色偏好。
- 累计与今日统计、旧版迁移和可替换历史补录。
- 小时显示、持续完成卡片与约 10 秒铃声。
- 保持手动衔接；不增加任务管理、历史图表、账号或同步。

## 验证与交付

Windows 自动构建执行类型检查、前端构建、计时测试与 NSIS 打包。测试范围见 [VALIDATION.md](VALIDATION.md)，数据与提交边界见 [PRIVACY.md](PRIVACY.md)。
